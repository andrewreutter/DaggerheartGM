# Daggerheart environment creation (app-aligned)

## Types and tiers

- **Types:** traversal, exploration, social, event.
- **Tiers:** 1–4 — reflect environmental danger and complexity; `difficulty` is a static DC-style value the GM uses when the environment calls for rolls.

## SRD examples in the API

- **Primary:** same **tier and type** — full environment cards (description, impulses, potential adversaries, features).
- **Secondary (features only):** same tier (all types) or same type (all tiers) — use for **feature naming and description patterns** only.

## Output shape

- **Impulses:** what drives scenes in this place.
- **Potential adversaries:** name placeholders (`{ name }`); the app may link them to library adversaries later.
- **Features:** environment features (action/reaction/passive) with clear GM-facing text.
