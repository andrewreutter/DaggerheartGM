# V2 Blocked resolutions — completed (archive)

This file is the **append-only archive** of **Done** rows from the **Blocked / API Extension Requests** workflow. The **active** pending work (only `Open` or `In Progress`) lives in **GitHub Issues** with the `v2-migration` label and `v2-kind:blocked`.

**Why split:** GitHub Issues stay queryable for unfinished API work; this file preserves implementation notes and cross-feature resolution history without duplicating the active queue.

## Agent maintenance (mandatory)

When the Unblocking Agent (or user) marks a resolution **Done** and the user approves:

1. **Append** the full row (same columns) to the table below — preserve Resolution, Features, SRD Requirement, Status (`Done`), Agent, and Notes.
2. **Close or update** the corresponding GitHub Issue (remove from the active Blocked query).
3. **Do not delete** rows from this archive except to fix clear duplication errors; history is intentional.
4. Optionally note the archive append in the Issue body.

**Promotion rule:** A feature’s row in the Feature Checklists is ready to move from `Blocked` to `Done` when **no open Blocked Issue** lists that feature in the Features column. (Completed resolutions only appear here in the archive; they no longer block.)
