# V2 Blocked resolutions — completed (archive)

This file is the **append-only archive** of **Done** rows from the **Blocked / API Extension Requests** workflow. The **active** pending table (only `Open` or `In Progress`) lives in [`v2-migration-tracker.md`](v2-migration-tracker.md) under the heading **Blocked / API Extension Requests**.

**Why split:** The migration tracker stays scannable for unfinished API work; this file preserves implementation notes and cross-feature resolution history without duplicating the active queue.

## Agent maintenance (mandatory)

When the Unblocking Agent (or user) marks a resolution **Done** and the user approves:

1. **Append** the full row (same columns) to the table below — preserve Resolution, Features, SRD Requirement, Status (`Done`), Agent, and Notes.
2. **Remove** that row from the active Blocked table in `docs/v2-migration-tracker.md`.
3. **Do not delete** rows from this archive except to fix clear duplication errors; history is intentional.
4. Update the **Last updated** line at the bottom of `v2-migration-tracker.md` (and optionally note the archive append).

**Promotion rule (main tracker):** A feature’s row in the Feature Checklists is ready to move from `Blocked` to `Done` when **no row in the active Blocked table** lists that feature in the Features column. (Completed resolutions only appear here in the archive; they no longer block.)
